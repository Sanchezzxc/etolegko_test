# Замер скорости скачивания

Консольный скрипт на Python. Делает 10 последовательных запросов к указанному адресу, на каждый дожидается полного ответа, затем выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

- Python 3.9 или новее
- Сторонние зависимости не нужны, используется только стандартная библиотека

## Запуск

```bash
git clone https://github.com/Sanchezzxc/etolegko_test.git
cd etolegko_test
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

На Linux/macOS вместо `python` может понадобиться `python3`.

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `url` | адрес, к которому делаются запросы | обязательный |
| `-n`, `--count` | число запросов | `10` |
| `-t`, `--timeout` | таймаут одного запроса, в секундах | `60` |

## Пример вывода

```
URL: https://proof.ovh.net/files/10Mb.dat
Запросов: 10

[ 1/10]   10.00 МБ     3646.0 мс      2.74 МБ/с
[ 2/10]   10.00 МБ     3664.8 мс      2.73 МБ/с
...
[10/10]   10.00 МБ     3569.3 мс      2.80 МБ/с

Успешных запросов:     10/10
Среднее время запроса: 3608.2 мс
Всего скачано:         100.00 МБ (104857600 байт)
Скорость скачивания:   2.77 МБ/с (23.25 Мбит/с)
```

## Единицы измерения

- **Время запроса** выводится в миллисекундах (мс). Отсчёт идёт от отправки запроса до получения последнего байта тела ответа, так что сюда входят DNS, соединение, TLS и само скачивание.
- **Объём** выводится в байтах и в двоичных единицах: 1 КБ = 1024 Б, 1 МБ = 1024 КБ.
- **Скорость** — основная единица **МБ/с** (мебибайты в секунду, 1 МБ = 1 048 576 байт). В скобках та же скорость в **Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит), в которых обычно указывают тарифы провайдеров.

Итоговая скорость считается как общий объём, делённый на суммарное время всех успешных запросов. Среднее время равно суммарному времени, делённому на число успешных запросов.

## Детали

- Запросы идут строго по очереди: следующий начинается после того, как предыдущий ответ дочитан до конца.
- Отправляются заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity`, чтобы не получать закешированный или сжатый ответ и считать реальный объём файла.
- Если какой-то запрос упал (HTTP-ошибка, таймаут, сеть), он пропускается и в статистику не попадает.
- Коды выхода: `0` — все запросы успешны, `2` — часть запросов упала, `1` — не удался ни один.
